# Tutorial-CW

This repo contains multiple intro-level examples introducing the concepts of side-channel analysis and fault injection attacks by using ChipWhisperer. For each example, we provide (1) a jupyter notebook, (2) a detailed tutorial document, and (3) a tutorial video covering each step.
